# ExpoSlides Studio

React + TypeScript интерфейс локального дизайнера: материалы → редактируемый план →
три варианта → замечания на слайде → выбранные исправления → экспорт. Сервер:
`exposlides/studio.py`. Результат сборки лежит в `exposlides/studio_static` и обслуживается
локально, включая React; CDN и внешние шрифты не нужны.

```bash
cd frontend
npm ci
npm run typecheck
npm test
npm run build
```

`npm test` запускает офлайн-проверки контрактов, импортов, выбора исправлений,
координат подсветки и серверного рендера React. Они дополняют ручную проверку браузером,
но не подтверждают совместимость всех версий браузеров из ТЗ. `npm ci` требует доступ
к реестру либо заранее заполненный npm-кеш; проверка и сборка после установки работают
без сети. Версии зависимостей закреплены в `package-lock.json`.

## Материалы

TXT: текст UTF-8 до 100 000 символов. Импорт заменяет исходный текст после подтверждения.
CSV: UTF-8, разделитель запятая или точка с запятой, заголовок из 2–20 разных столбцов,
1–200 строк. Кавычки, переносы строк внутри кавычек и десятичная запятая при разделителе
`;` поддерживаются. Единицы измерения можно уточнить после импорта.

JSON-пакет UTF-8 до 2 МБ заменяет текст, обязательные тезисы и таблицы после подтверждения.
Обязателен `script`; остальные поля можно опустить. `purpose` и `audience` при отсутствии
сохраняют текущие значения. Неизвестные поля отклоняются; импорт не включает модели,
генератор иллюстраций и дополнительные внешние проверки.

«Предыдущие работы» открывает сохранённые на сервере задания текущего браузера.
Список и каждый файл проверяются сервером по постоянной HttpOnly cookie владельца;
после очистки cookies доступ к прежней истории из браузера теряется. Материалы других
владельцев не включаются в ответ. При перезапуске страницы последняя работа
восстанавливается из sessionStorage: временная ошибка связи не стирает её ссылку.
Частично успешная сборка показывает уже опубликованные варианты и причину сбоя,
без заявления о готовности всех трёх. Скачивание и аудит доступны, автоматические
исправления разрешаются после успешной сборки.

```json
{
  "script": "В 2025 году выручка составила 5 млн рублей, в 2026 — 8 млн рублей.",
  "purpose": "Представить результаты года",
  "audience": "Команда",
  "required_messages": ["Показать значения за оба года"],
  "datasets": [{
    "id": "revenue",
    "name": "Выручка",
    "columns": ["Год", "Выручка"],
    "rows": [["2025", 5], ["2026", 8]],
    "source": "Годовой отчёт",
    "unit": "млн руб."
  }]
}
```

До 50 обязательных тезисов и 20 наборов данных. `id` набора уникален, содержит 1–80
латинских букв, цифр, `_` или `-`. Ячейки — строки или конечные числа; все строки
прямоугольные, `source` непустой. Сервер повторно валидирует итоговый `DesignRequest`.

Генерация иллюстрации и проверка смысла по изображениям включаются отдельными флажками
и доступны только после подтверждения возможностей сервера (`/api/capabilities`).
Иллюстрация по умолчанию выключена; при включении пользователь задаёт описание,
сервер берёт палитру шаблона и добавляет общее изображение в три варианта.
Проверочный режим отключает обе внешние функции. Неудача генератора не маскируется
декоративной заглушкой; интерфейс показывает ошибку сервера.
