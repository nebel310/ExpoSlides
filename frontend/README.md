# ExpoSlides Studio

React + TypeScript интерфейс локального дизайнера. Три страницы:

- **Загрузка:** PPTX-шаблон, текст или TXT, необязательные данные для графиков, число слайдов и кнопка создания.
- **Результат:** крупный предпросмотр, миниатюры, переключение слайдов и скачивание PPTX/PDF/HTML и раскрываемая проверка качества с выбором исправлений.
  Доступные варианты выбираются карточками «Вариант 1–3» с превью текущего слайда.
  При переключении сохраняется позиция слайда, чтобы сравнивать оформление.
- **История:** сохранённые презентации текущего браузера, дата и статус.

Планирование и сборка выполняются автоматически на сервере после одного нажатия.
Основная форма остаётся простой. Готовый результат содержит раскрываемый аудит:
замечания, области проблем и выбор доступных исправлений с созданием новой версии.
Для задания, остановившегося на готовом плане, доступен редактор слайдов и продолжение
сборки. Расширенные настройки назначения и модели остаются в API.

Сервер: `exposlides/studio.py`. Сборка находится в `exposlides/studio_static`;
React, стили и системные шрифты используются локально, CDN не нужен.

```bash
cd frontend
npm ci
npm run typecheck
npm test
npm run build
```

Тесты работают без сети: проверяют API, восстановление состояния, доступные действия
и серверный рендер React. Браузерная проверка дополняет их, но не подтверждает всю
матрицу браузеров и ОС из ТЗ. Для установки зависимостей нужен npm-кеш или реестр.

## Данные и восстановление

PPTX — до 25 МБ. TXT — UTF-8, до 100 000 символов. Генерация использует настроенную
текстовую модель; при её недоступности сценарий не подменяется локальной имитацией.
Запущенная генерация продолжает работать без открытой вкладки. Её состояние и готовые
файлы восстанавливаются из истории. При уходе с результата через навигацию, логотип или
кнопку возврата очищаются шаблон, текст, таблицы, число слайдов и выбранная работа.
Можно сразу начать другую презентацию: предыдущая продолжает создаваться на сервере.
История показывает все работы и автоматически обновляет статусы незавершённых.
Повторное открытие работы из истории возвращает её результат или текущий прогресс.

Обновление вкладки восстанавливает только открытый результат. После явного ухода с него
обновление открывает чистую форму; ссылка на работу остаётся в истории. Временная ошибка
связи при восстановлении не удаляет сохранённую ссылку. Поздние ответы загрузки, открытия,
отмены или исправления старой работы не меняют новую форму и не блокируют новую отправку.
Частично готовый результат позволяет скачать уже созданные файлы и показывает ошибку.

Список работ и скачивание защищены постоянной HttpOnly cookie владельца. После очистки
cookies прежняя история недоступна из этого браузера; чужие работы не выдаются.

## API

`POST /api/design/generate` принимает `{template_id, request}` и запускает единый
процесс от планирования до результата. Проверки фактов, лимит времени, очередь,
отмена и сохранение промежуточных результатов остаются на сервере.

Раздельные `/api/design/plan`, `/build` и `/fix` сохранены для совместимости API.
Таблицы из поля «Добавить таблицы Excel/CSV» передаются в request.datasets и сохраняются
в серверной работе. После ухода с результата новая форма начинает работу без этих таблиц.
Обязательные тезисы и параметры моделей остаются доступны программно.

## Загрузка шаблона

Чтение и передача PPTX имеют отдельное состояние: во время загрузки доступны ввод
текста и импорт TXT. Генерация и повторная отправка шаблона ждут окончания загрузки.
Интерфейс показывает чтение файла, процент передачи и ожидание проверки сервером.
Передача ограничена пятью минутами вместо общего 45-секундного тайм-аута API.
Сессия запрашивается без кеширования перед отправкой; POST не повторяется автоматически.
Ошибка загрузки сохраняет текст и ранее выбранный шаблон.

`npm test` также проверяет ошибки загрузки и работу React-формы в jsdom при
незавершённом запросе: ввод, импорт TXT и сохранность текста после успеха или ошибки.

## Пауза во время генерации

Пока готовится презентация, на экране результата доступна мини-игра «Соберите палитру».
Шесть оттенков нужно расположить слева направо от светлого к тёмному.
Два нажатия меняют выбранные карточки местами; повторное снимает выделение.
Собранные оттенки обводятся зелёной рамкой; через 0,65 секунды автоматически появляется
следующая палитра. Кнопки перехода нет. Нет ограничения времени или проигрыша; игру можно свернуть.
Игра не меняет презентацию и исчезает при появлении результата или остановке генерации.
Управление доступно мышью, касанием и клавиатурой (Tab, Enter/пробел).

Если в названии макета PPTX встречаются неэкранированные кавычки, студия может
подготовить внутреннюю совместимую копию, когда корректное имя есть в том же макете.
Загруженный оригинал сохраняется побайтово; генерация использует рабочую копию.
Другие повреждения файла и ограничения размера по-прежнему проверяются.

## Данные для графиков

Поле «Добавить таблицы Excel/CSV» открывает выбор CSV/TSV в UTF-8 до 400 КБ каждый.
Можно выбрать несколько файлов; отображаются имена и удаление, без пояснений,
редактора ячеек и предпросмотра. Название и источник берутся из имени файла.
Первый столбец сохраняется как подписи, включая ведущие нули, остальные — числа.
До 20 таблиц и 20 столбцов; лимита строк нет, в запрос передаются все строки.
Графики строятся из исходных значений; модель выбирает уместную визуализацию.
Прямой импорт XLSX и извлечение рядов из текста не реализованы.

## Экспорт HTML

В просмотрщике рядом с PPTX и PDF доступна кнопка HTML для выбранного варианта.
Она скачивает автономный файл: слайды, текст и таблицы встроены внутрь, подключение
к серверу для просмотра не требуется. Кнопка появляется только при наличии экспорта.

При переходе на другую страницу незавершённый импорт CSV перестаёт блокировать
действия. Его поздний результат не перезаписывает материалы другой работы.

## Интерфейс сетевого gateway

`gateway/` содержит отдельный интерфейс из удалённой ветки dev. Сервис `frontend`
корневого Compose публикует его на `http://localhost:2000` и передаёт API/WS
в gateway. React-студия собирается из `src/` через `npm run build`.
