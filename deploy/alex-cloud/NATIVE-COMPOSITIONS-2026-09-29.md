# Разнообразие и фотографии внутри исходных масок — 29 сентября 2026

Новый релиз: `20260929-native-compositions-01`.
Предыдущий релиз и откат: `20260929-template-first-01`.

## Причины

В пользовательском шаблоне 55 слайдов: обложки, карточки, списки, иконки,
фотографии, схемы, таблицы и заключительные слайды. В шаблоне нет цикла
35 → 36 → 34 → 24. Его создавал планировщик, предпочитавший небольшое число
макетов по стоимости. Прежний аудит замечал только одинаковую композицию подряд.

Фотографии образцов 35/36 находятся в layout, внутри настоящего `a:custGeom`.
Профиль распознавал заменяемые фотографии только на слайде. Механическая смена
макетов дополнительно выявила проблему исходного плана: почти везде два тезиса,
поэтому шаблоны с четырьмя–шестью блоками получались полупустыми.

## Изменения

- Заполненные, вместимые композиции предпочтительнее полупустых. Среди них
  выбираются неиспользованные, с учётом числа тезисов. Основной вариант использует
  порядок исходных образцов, пока они подходят. При необходимом повторе
  штрафуются уже встречавшиеся переходы между макетами.
- Аудит отмечает короткие циклы из двух–четырёх композиций (`layout_cycle`).
- Планировщик получает число смысловых блоков подходящих макетов без текста
  образцов. Достоверность важнее заполнения: новые факты ради количества запрещены.
- Крупные фотографии layout распознаются отдельно от фотографий слайда.
  Логотипы, фон, мелкий декор и фотографии master остаются защищёнными.
- Фото заменяются внутри исходной фигуры: сохраняются custom geometry,
  положение, размер, порядок и эффекты. Кадрирование центральное, без растяжения.
  Несколько областей одного слайда используют одну тематическую иллюстрацию.
- При замене layout-фото создаются независимые layout/master с корректными
  обратными ссылками и регистрацией в презентации. Соседние слайды не меняются.
- Аудит проверяет реальные байты нового фото, форму маски, кадрирование и
  неизменность остальных объектов, темы и мастера.

Схема Studio расширена совместимыми полями `layout_images`, `image_fit` и
`source_layer`; старые профили/планы загружаются с прежними значениями по умолчанию.
Межсервисный Presentation JSON и зависимости не менялись.
