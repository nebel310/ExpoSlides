# Три различимые версии по шаблону

Исправление требования раздела 2, пункта 5 ТЗ «4. VK Tech.pdf»: три визуально
различимые версии одной истории, сохраняющие правила загруженного шаблона.
Активный релиз: `20260929-layout-catalog-01`.

## Изменения

- `exposlides/template_catalog.py` — рабочая копия с дополнительными образцами из
  встроенных layouts всех masters; исходный PPTX неизменен. Пропускаются специальные
  пустые placeholders и большие незаполненные панели. Реальные фото сохраняются.
  SHA-256 связывает исходник, каталог и профиль, в том числе при последующих исправлениях.
- `exposlides/template_layout.py` — сравнение геометрии/типографики вместо номеров
  исходных слайдов; вместимость и заполненность важнее разнообразия. Заголовок,
  помещающийся в свою область, предпочтительнее переполняющегося. Генератор получает
  бюджет заголовка, рассчитанный также для узких фото-макетов.
- `exposlides/design_diversity.py` — попарная проверка: различается не менее половины
  содержательных слайдов; общая обложка допустима. Номера образцов и ID фигур сами
  по себе не считаются отличиями. Ось различий — выбор/последовательность нативных
  композиций и размещение тезисов в предусмотренных областях.
- `exposlides/design_pipeline.py` — подключение каталога при планировании и сборке,
  отчёт `variant-diversity.json`, отказ от одинаковых версий до генерации изображений.
- `exposlides/design_native_text.py` — чтение уровня абзаца без скрытого добавления
  XML-элементов в layout/master; наследуемое оформление не меняется при чтении.
- `prompts/designer/story.md` — короткие предметные заголовки по вместимости шаблона.
- `tests/test_template_catalog.py` — восемь офлайн-регрессий, включая fake LLM,
  неизменность исходника, настоящие фото, пустые панели, целостность каталога,
  наследуемые стили, переполнение заголовков и отказ от одинаковых вариантов.
- `README.md`, `evals/README.md`, `deploy/alex-cloud/README.md` — поведение,
  ось различий, проверки и ссылка на этот отчёт.

На сервер переносились только изменения этой задачи поверх фактически активного
релиза. Другие незакоммиченные изменения локального дерева не переносились.
Зависимости, секреты и межсервисные модели не менялись.

сохранены в `images/slide-{5,9}/catalog-diagram.{png,json}`. Остальные иллюстрации прежние.

время замены метаданных и ссылки current. Исходный `template.pptx` побайтно сохранён.
Старые revision 1/2 доступны. Служба active, локальный HTTP 200, публичный HTTPS без
авторизации 401. Через API проверены три revision 3, все экспорты и 36 предпросмотров;
скачанные PPTX повторно открыты, notes совпадают. Содержимое файлов совпадает с диском.
