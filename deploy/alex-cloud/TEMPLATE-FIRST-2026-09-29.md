# Выбор исходных композиций шаблона — 29 сентября 2026

Релиз: `20260929-template-first-01`, основа и откат: `20260929-upload-labels-01`.

## Причина и исправление

В последней презентации «Важность чтения книг» 11 из 12 слайдов во всех вариантах
использовали образец № 8. Автоиллюстрации включались для всех содержательных слайдов;
если выбранный текстовый макет не имел области фото, включалась свободная верстка.
Её порог 90% максимальной вместимости оставлял единственного кандидата — № 8.

Теперь автоматическая генерация сначала выбирает исходные композиции с учётом
вместимости и повторов. Иллюстрации запрашиваются только для слайдов, где хотя бы
один вариант использует единственную заменяемую область фото. В каждом варианте
изображение заполняет эту область; текстовые макеты сохраняют исходную геометрию.
Макеты с несколькими фото, фотографии в фоне/master/layout, логотипы и декор
сохраняются. Для явно заданной иллюстрации сначала ищется совместимый нативный
фото-макет; свободная верстка остаётся резервом этого явного режима и визуализаций.

Аудит предупреждает о трёх последовательных повторах одной композиции, даже при
разном содержании. Единственный пригодный макет по-прежнему можно повторить:
разнообразие не оправдывает переполнение текста.

## Изменённые файлы

- `exposlides/design_layout.py`: режим автоизображений без изменения композиции.
- `exposlides/template_layout.py`: фильтрация фото-макетов до выбора для явного изображения.
- `exposlides/design_pipeline.py`: выбор целей генерации по нативным областям.
- `exposlides/design_audit.py`: предупреждение `repeated_layout`.
- `tests/test_design_images_batch.py`: выборочное создание изображений, сохранение
  текста, координат и логотипов при повторном открытии настоящего PPTX.
- `tests/test_template_layout.py`: обнаружение одинаковой композиции при разных текстах.
- `README.md`, `evals/README.md`, `deploy/alex-cloud/README.md` и этот отчёт.

результаты остаются в revision 1; проверенные результаты добавляются как revision 2
того же задания. Метаданные до изменения сохраняются в
`shared/deploy-backups/20260929-template-first-01`.

Для отката приложения при отсутствии активных заданий атомарно вернуть current на
`/home/alex/exposlides/releases/20260929-upload-labels-01` и перезапустить exposlides.
Путь также записан в `TEMPLATE_FIRST_PREVIOUS_RELEASE` нового релиза.

variants.json из указанной резервной копии и запустить службу. Файлы обеих ревизий
сохраняются; шаблоны и пользовательские исходники не изменяются.
