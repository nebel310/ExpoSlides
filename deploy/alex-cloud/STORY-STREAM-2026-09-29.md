## Подготовленное исправление

`story-stream-20260929.patch` меняет четыре файла актуальной серверной версии:

- `services/content-service/app/chains/chat_completions.py`: при stream=true
  читает SSE через httpx, собирает первую completion и требует finish_reason=stop
  и событие [DONE]. Обрыв, неполный JSON, усечение, фильтр и ошибки провайдера
  отклоняются. Соединение закрывается при успехе, ошибке и отмене. Ответ ограничен
  4 МиБ. Для провайдера, вернувшего application/json, сохраняется прежний разбор.
- `services/content-service/app/chains/llm.py`: FastLLMClient принимает опцию stream,
  выключенную по умолчанию. Ограничения времени и повторов остаются прежними.
- `services/content-service/app/design_main.py`: только планировщик Studio использует
  отдельный FastLLMClient(stream=True). Полная Pydantic-проверка, grounding и
  проверка обложки сохраняются. Нет подмены результата extractive-планом.
- `tests/test_openrouter_transport.py`: 13 новых офлайн-регрессий потокового
  транспорта, включая разбиение UTF-8 между чанками, HTTP-ошибки и отмену.

Потоковый режим документирован в API Hugging Face:
https://huggingface.co/docs/inference-providers/main/en/tasks/chat-completion
Его эффективность для данного сбоя требует проверки на сохранённых материалах;
успех юнит-тестов сам по себе её не подтверждает.

## Дополнение: корректировка без повторной генерации всего плана

Первый интеграционный запуск потокового транспорта получил завершённый ответ
за 127.51 с (без 504), но валидация потребовала исправлений, а повторная генерация
всего плана не уложилась в оставшийся бюджет. Этот запуск закончился timeout и
не является успешной проверкой исправления.

В design_main.py добавлена передача предыдущего плана в корректирующий запрос.
При правильном числе слайдов модель возвращает только исправляемые слайды; они
заменяются по существующим id, остальные сохраняются. Неизвестные id отклоняются.
При ошибке количества слайдов по-прежнему запрашивается полный план. Весь
объединённый результат снова проходит прежний grounding и проверку обложки.
Предел попыток и общий timeout не меняются.

Пятый файл патча — tests/test_design_generation.py: проверка частичного ремонта,
отклонения неизвестных id и полной генерации при неверном числе слайдов.
Целевые тесты после изменения: 112 passed. Ruff изменённых файлов прошёл.
Повторная интеграционная проверка пишет закрытые ответы в verification/attempt-v2-*.json
для анализа ошибок без публикации материалов в логах.


## Повторная проверка и окончательный состав кандидата

Кандидат дополнен частичным исправлением плана: в повторный запрос включаются
предыдущий план и ошибки; ответ может содержать только изменённые слайды.
Остальные слайды сохраняются, объединённый план проходит прежние проверки.
Неизвестные ID отклоняются; неверное число слайдов требует полного плана.
В запросе отдельно разъясняется перенос содержательных фактов с тесной обложки
на следующий слайд с соответствующими source_ids; notes не заменяют видимый текст.

Бюджет story увеличен с 180 до 240 секунд при прежнем общем лимите 300 секунд;
ограничение других ролей остаётся 180 секунд. Версия designer — 1.1.1.
Дополнительно затронуты agents/designer.toml, app/design_config.py,
tests/test_design_generation.py, tests/test_design_agent_config.py — всего восемь файлов.
