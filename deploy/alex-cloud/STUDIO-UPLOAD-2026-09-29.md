Старый frontend использовал один busyAction для загрузки PPTX и текстовых полей.
Общий тайм-аут 45 секунд распространялся также на передачу файла. Конкретный файл,
браузер и сообщение об ошибке пользователя не предоставлены, поэтому причина
именно его отказа пока не доказана.

Через публичный HTTPS с существующей авторизацией проверены синтетические PPTX:
малый файл — HTTP 201 за 0.31 с; файл 25 200 729 байт (около 24 МиБ) — HTTP 201
за 5.39 с. Большой PPTX повторно открыт через python-pptx: 5 слайдов. Эти замеры
сделаны до установки исправления. Они подтверждают работоспособность серверного
маршрута, но не воспроизводят медленное соединение пользователя. Реального вызова
LLM не было, пароли и ключи не выводились.
