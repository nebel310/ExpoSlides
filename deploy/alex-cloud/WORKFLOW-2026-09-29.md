- В UI отсутствовал доступ к редактированию плана, выбору замечаний, исправлениям
  и их областям. Добавлены просмотр замечаний, исправления и ссылки на предыдущие
  экспорты; сохранённые планы доступны для редактирования. Дополнительные поля формы
  затем удалены по уточнению пользователя, как описано ниже.
- Заполненный диск приводил к HTTP 500 при загрузке и ошибке парсинга с сообщением
  о модели. Освобождён неиспользуемый Docker build-кэш старше суток и кэш uv;
  контейнеры, образы, volumes, секреты, история и релизы не удалялись.
  Кандидат переиспользует неизменённые зависимости базового релиза через ссылки.
  Перед загрузкой/запуском/исправлением проверяется запас 256 МиБ, для загрузки
  дополнительно три размера входного файла. При недостатке — HTTP 507.
  Это предварительная проверка, не резервирование места для параллельных задач.
- Варианты реальных шаблонов совпадали. Один непригодный слот приводил к отказу
  от всей композиции. Теперь выбираются непересекающиеся пригодные области;
  учитываются композиции других вариантов. Вместимые макеты имеют приоритет,
  геометрия, порядок текста и защищённые объекты сохраняются.
- Benchmark не находил фигуры с сохранёнными именами. Он теперь учитывает source_shape_id,
  включая номера страниц. Критерий различия соответствует ТЗ: три различные колоды,
  а не обязательное различие каждого слайда. Метрика по каждому слайду сохранена.
