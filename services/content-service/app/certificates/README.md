# Сертификат для быстрого профиля GigaChat

`russian_trusted_root_ca.pem` — публичный корневой сертификат Russian Trusted Root CA,
выпущенный НУЦ Минцифры. Он не содержит закрытого ключа.

- Источник: <https://gu-st.ru/content/lending/russian_trusted_root_ca_pem.crt>.
- Официальная документация: <https://developers.sber.ru/docs/ru/gigachat/certificates>.
- Получен 22 сентября 2026 года по HTTPS с включённой проверкой сертификата сервера.
- SHA-256 сертификата в DER: `d26d2d0231b7c39f92cc738512ba54103519e4405d68b5bd703e9788ca8ecf31`.
- Срок действия: 1 марта 2022 года, 21:04:15 UTC — 27 февраля 2032 года, 21:04:15 UTC.

Быстрый клиент создаёт отдельный `SSLContext`, сохраняет стандартные доверенные CA и
добавляет этот корневой сертификат. Проверка цепочки и имени сервера остаётся включённой.
Контекст используется только SDK быстрого профиля, включая OAuth; системное хранилище,
файлы `certifi` и стандартный профиль не меняются.

При заданной переменной окружения `GIGACHAT_CA_BUNDLE_FILE` SDK использует указанный
пользователем файл вместо встроенного контекста. Такой файл должен содержать все CA,
нужные настроенному API и серверу OAuth. Пользовательские HTTPS-адреса со стандартными
сертификатами работают с контекстом по умолчанию; для частного CA нужен явный bundle.

Для обновления скачайте новый сертификат из официального источника с проверкой HTTPS,
проверьте его издателя, срок действия и отпечаток, затем обновите файл и эту запись.
Приложение не загружает и не обновляет сертификаты автоматически.
