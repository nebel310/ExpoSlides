        1. 01

          Добавьте свой шаблон

          Нужен PPTX с текстовыми заполнителями — заголовками и блоками для основного текста. Обычные текстовые поля не заменяются.

        2. 02

          Расскажите главное

          Вставьте текст или загрузите файл .txt в UTF-8. Включите факты и выводы, которые хотите донести.

        3. 03

          Заберите презентацию

          Скачайте редактируемый PowerPoint. Проверьте содержание и размещение текста перед выступлением.

        Для сборки нужен настроенный доступ к Qwen. Исходный текст и текстовая структура шаблона отправляются через Hugging Face провайдеру DeepInfra только после нажатия «Создать презентацию». Просмотр примера работает без генерации.

        Файлы доступны до остановки локального приложения. Скачайте результат перед закрытием сервера.
